# Программа-анализатор NGINX логов

**Программа-анализатор NGINX логов** предназначена для автоматизации обработки и анализа лог-файлов сервера. Она помогает быстро получить полезную статистику без необходимости ручного анализа.

## Основные возможности

- **Подсчёт общего количества запросов**
- **Определение наиболее часто запрашиваемых ресурсов**
- **Анализ наиболее популярных кодов ответа**
- **Расчёт среднего размера ответа сервера**
- **Определение 95-го перцентиля размера ответа сервера**
- **Работа с диапазоном времени анализа (ISO8601)**
- **Выбор формата отчёта:** Markdown или AsciiDoc (`adoc`)

## Примеры вызовов

```bash
analyzer --path logs/2024* --from 2024-08-31 --format markdown
analyzer --path https://raw.githubusercontent.com/elastic/examples/nginx_logs --format adoc
analyzer --path logs/**/2024-08-31.txt
```

## Ключевые особенности

- **Эффективная обработка:** Не загружает весь файл в память, что делает обработку логов быстрой и эффективной.
- **Гибкость источников:** Поддерживает как локальные файлы (шаблоны glob), так и URL.
- **Удобство использования:** Простая навигация по ошибкам и формирование понятных отчётов.

## Идеально подходит для

Этот инструмент идеально подходит для системных администраторов и разработчиков, которые хотят быстро анализировать логи и находить ключевые показатели.
